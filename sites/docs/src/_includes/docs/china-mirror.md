Ele inclui o SDK do Flutter e os pacotes do pub.

#### Configure sua máquina para usar este espelho {:#configure-your-machine-to-use-this-mirror}

Para configurar sua máquina para usar este espelho, use estes comandos.

No macOS, Linux ou ChromeOS:

```console
export PUB_HOSTED_URL={{pubHosted}}
export FLUTTER_STORAGE_BASE_URL={{flutterStorage}}
```

No Windows:

```console
$env:PUB_HOSTED_URL="{{pubHosted}}"
$env:FLUTTER_STORAGE_BASE_URL="{{flutterStorage}}"
```
